================================================================================
STM32水质检测系统 - 蓝牙连接上位机使用手册
================================================================================

版本：V1.0
日期：2026-04-28
适用系统：STM32F103C8T6 + HC-05蓝牙模块

================================================================================
一、系统概述
================================================================================

本系统通过HC-05蓝牙模块将STM32采集的水质数据传输至上位机页面进行实时显示。
上位机页面使用Web Bluetooth API，通过浏览器直接连接蓝牙设备，无需安装额外软件。

监测参数：
- 水温（DS18B20传感器）
- pH值（pH传感器）
- 浊度（浊度传感器）
- TDS值（TDS传感器）

================================================================================
二、硬件准备
================================================================================

2.1 所需硬件
-----------
- STM32F103C8T6最小系统板
- HC-05蓝牙模块
- DS18B20温度传感器
- pH传感器模块
- 浊度传感器模块
- TDS传感器模块
- OLED显示屏（I2C接口）
- 杜邦线若干
- 5V电源

2.2 HC-05接线方式
-----------------
HC-05引脚         STM32引脚
---------         ---------
VCC          -->  5V
GND          -->  GND
TX           -->  PB11 (USART3_RX)
RX           -->  PB10 (USART3_TX)
KEY          -->  悬空（透传模式）
STATE        -->  不连接

注意事项：
- TX/RX必须交叉连接（HC-05的TX接STM32的RX）
- HC-05工作电流约30-40mA，建议使用独立5V供电
- HC-05上电后LED快速闪烁表示待机状态

2.3 其他传感器接线
-----------------
传感器            STM32引脚
------            ---------
DS18B20      -->  PA8
pH传感器      -->  PA1 (ADC_CH1)
浊度传感器    -->  PA0 (ADC_CH0)
TDS传感器     -->  PA2 (ADC_CH2)
OLED SCL     -->  PB6
OLED SDA     -->  PB7
继电器        -->  PB0
蜂鸣器        -->  PC13
按键1-4       -->  PB12-PB15

三、软件准备
================================================================================

3.1 浏览器要求
--------------
Web Bluetooth API仅支持以下浏览器：
- Google Chrome 56+ (推荐)
- Microsoft Edge 79+
- Opera 43+

不支持的浏览器：
- Firefox（不支持Web Bluetooth API）
- Safari（不支持Web Bluetooth API）

3.2 环境要求
------------
开发环境：可直接使用localhost打开HTML文件
生产环境：必须使用HTTPS协议

本地使用方法（最简单）：
1. 直接双击 index_bluetooth.html 文件用Chrome打开
2. 或者在Chrome地址栏输入文件的完整路径

3.3 电脑蓝牙要求
----------------
- 电脑必须内置蓝牙适配器或外接USB蓝牙适配器
- 蓝牙版本建议4.0及以上
- Windows 10/11系统自带蓝牙驱动

================================================================================
四、使用步骤
================================================================================

步骤1：硬件连接
---------------
1. 按照上述接线图连接HC-05蓝牙模块到STM32
2. 连接所有传感器
3. 给STM32上电
4. HC-05 LED灯应快速闪烁（表示待机状态，等待连接）

步骤2：烧录STM32程序
--------------------
1. 打开Keil uVision项目：USER/STM32_YFCDZ.uvprojx
2. 添加 usart3.c 到项目（如果尚未添加）：
   - 右键项目 -> Add Group -> 命名为"USART3"
   - 右键USART3组 -> Add Files -> 选择 SYSTEM/USART/usart3.c
3. 编译项目（F7）
4. 使用ST-Link连接STM32
5. 烧录程序（Download按钮）
6. 复位STM32

步骤3：打开上位机页面
---------------------
1. 打开Chrome或Edge浏览器
2. 双击打开 index_bluetooth.html 文件
3. 页面显示三个数据卡片（温度、pH、浊度）和实时趋势图
4. 初始状态显示"未连接"，数据卡片显示"--"

步骤4：连接蓝牙设备
--------------------
1. 点击页面上的"连接蓝牙"按钮
2. 浏览器弹出蓝牙设备选择窗口
3. 在列表中找到HC-05设备（名称通常为"HC-05"）
4. 点击"配对"按钮
5. 输入配对密码（默认为 1234 或 0000）
6. 连接成功后：
   - 状态指示器变为绿色
   - 状态文字变为"已连接"
   - HC-05 LED灯变为常亮
   - 数据卡片开始显示实时数值

步骤5：查看数据
---------------
连接成功后，页面将实时显示：
- 温度卡片：当前水温（单位：C）
- pH卡片：当前pH值
- 浊度卡片：当前浊度值（单位：NTU）
- 实时趋势图：三种参数的历史变化曲线
- 系统日志：记录连接状态和数据接收情况

步骤6：断开连接
---------------
点击"断开连接"按钮即可断开蓝牙连接

================================================================================
五、OLED按键操作说明
================================================================================

系统有4个按键，功能如下：

5.1 自动模式（默认）
--------------------
- KEY1：切换到手动模式
- KEY2：切换显示页面
- KEY3：无功能
- KEY4：无功能
- 长按KEY1：进入阈值设置模式

OLED显示内容：
第1行：水温：xx.x C
第2行：TDS：xxx ppm
第3行：浊度：xxxx
第4行：PH：xx.x

自动模式下，当任一参数超过设定阈值时：
- 蜂鸣器报警
- 继电器动作

5.2 手动模式
------------
- KEY1：返回自动模式
- KEY2：切换选项（继电器/蜂鸣器）
- KEY3：开启选中设备
- KEY4：关闭选中设备

5.3 阈值设置模式
----------------
- KEY1：退出设置并保存到Flash
- KEY2：切换设置项
- KEY3：增加数值
- KEY4：减少数值

可设置参数：
- 水温阈值（0-80）
- TDS阈值（0-999，步进10）
- pH上限（0-14）
- pH下限（0-14）
- 浊度阈值（0-2000，步进10）

================================================================================
六、数据格式说明
================================================================================

STM32通过蓝牙发送的数据格式为JSON：

{"temperature":25.5,"ph":7.2,"turbidity":2.5}

字段说明：
- temperature：水温，单位C，保留1位小数
- ph：pH值，保留2位小数
- turbidity：浊度，单位NTU，保留1位小数

发送频率：约每秒1次
波特率：9600bps

================================================================================
七、常见问题及解决方法
================================================================================

问题1：浏览器找不到蓝牙设备
---------------------------
原因：
- 浏览器不支持Web Bluetooth API
- 电脑蓝牙未开启
- HC-05未上电

解决：
- 使用Chrome或Edge浏览器
- 检查电脑蓝牙是否开启
- 检查HC-05电源和LED状态
- 点击"连接蓝牙"按钮后再搜索

问题2：连接成功但数据不更新
---------------------------
原因：
- STM32程序未正确烧录
- 传感器未连接
- 蓝牙数据传输异常

解决：
- 重新烧录STM32程序
- 检查传感器接线
- 断开重新连接蓝牙
- 检查系统日志中的错误信息

问题3：连接频繁断开
-------------------
原因：
- 蓝牙超出传输距离
- HC-05供电不稳定
- 蓝牙信号干扰

解决：
- 缩短设备间距离（有效距离约10米）
- 使用稳定的5V电源
- 远离WiFi路由器等干扰源

问题4：配对密码错误
-------------------
HC-05默认配对密码为 1234 或 0000
如果以上密码都不对，可通过AT指令重置：
1. 将HC-05的KEY引脚接到3.3V（AT指令模式）
2. 使用串口助手以38400波特率连接
3. 发送 AT+PSWD="1234" 重置密码
4. 断开KEY引脚，回到透传模式

问题5：页面显示"未接入设备"
----------------------------
原因：未连接蓝牙设备
解决：点击"连接蓝牙"按钮，选择HC-05设备连接

问题6：Keil编译报错
--------------------
常见错误及解决：
1. "undefined symbol usart3_init"：
   解决：将 usart3.c 添加到Keil项目中

2. "cannot open source input file usart3.h"：
   解决：在Keil项目设置中添加头文件路径

================================================================================
八、系统工作流程
================================================================================

1. STM32上电初始化
   - 初始化USART3（蓝牙通信）
   - 初始化ADC（传感器采集）
   - 初始化OLED显示
   - 初始化DS18B20温度传感器
   - 从Flash读取阈值设置

2. 主循环运行
   - 采集传感器数据（温度、pH、浊度、TDS）
   - 通过USART3发送JSON数据到HC-05
   - 更新OLED显示
   - 检测按键输入
   - 根据模式执行控制逻辑

3. 蓝牙数据传输
   - HC-05接收到USART3数据后通过蓝牙转发
   - 上位机页面通过Web Bluetooth API接收数据
   - 解析JSON并更新显示
