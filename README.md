# -MiMo-Agent-
我构建了基于小米 MiMo 大模型的智能水产养殖水质监测与闭环调控 Agent 系统，解决了传统养殖中水质诊断滞后、依赖人工、异常响应迟缓的痛点，避免无人值守时因水质异常造成养殖损失。 系统核心为多 Agent 协作 + 闭环控制：STM32 单片机采集水质数据并上传，通过 MiMo API 实现数据解析、异常诊断与调控决策，最终由控制执行 Agent 下发指令，自动驱动继电器、水泵等外设调节水质，达成 “感知 - 诊断 - 决策 - 执行” 全链路自动化。 预期可实现 7×24 小时无人值守，将异常响应时间从人工操作的 30 分钟压缩至秒级，显著降低人工成本与养殖风险，提升水产品成活率。
